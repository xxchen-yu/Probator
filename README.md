# Probator

面向 AI 智能体的回归测试与上线门禁工具。

智能体修改提示词、更换模型或更新知识库之后，行为变化难以量化。人工抽检不可复现，仅检查最终回答无法定位失败环节，以模型评分作为唯一标准则稳定性不足。

Probator 将判定拆分为三个层次，把结论收敛为可比较的回归结果，并以退出码接入 CI。

## 判定体系

**L1 规则层**

对输出文本执行关键词、格式、必含与必不含内容等规则断言。

**L2 语义层**

由模型按维度评分。结果仅作为参考信号，不单独决定结论。

**L3 决策层**

依据 trace 检查动作序列，包括：

- 计划动作与实际调用是否一致
- 检索是否实际发生
- 引用的条款是否有效
- 答案中的数字是否可溯源
- 工具失败是否被如实上报

目标未提供 trace 时，仅执行 L1 与 L2，并标注决策层未覆盖。

## 变异体校准

判定逻辑本身需要验证。平台内置六类故障注入：

- 检索缺失
- 引用废止条款
- 工具静默失败
- 计划与执行不一致
- 数字编造
- 越权动作

对注入样本执行判定，统计检出率与归因集中度。结果持久化保存，服务重启后可查看。

## 多采样与三态判定

同一用例执行多次，结果分为通过、不稳定、失败三态。不稳定与失败同样阻断发布。

## 回归对比

每次执行留存结果，可与基线比较，输出回归、修复、新增不稳定三类差异，支持导出 Markdown。

## 能力自适应

目标能力由配置声明。缺少 trace 时不执行 L3，也不将不可观测判定为失败。

## 快速开始

环境要求：Python 3.9 及以上。

启动被测智能体：

```powershell
cd 待测智能体
Copy-Item .env.example .env
python agent_server.py
```

服务地址为 `http://127.0.0.1:8000`。运行前需在 `.env` 中配置模型地址与密钥。

启动测试平台：

```powershell
cd 平台
pip install -r requirements.txt
python server.py
```

服务地址为 `http://127.0.0.1:8500`。选择目标配置 `seed.json` 后执行。

命令行门禁：

```powershell
cd 平台
python run.py
python run.py --samples 3 --fail-under 95
python run.py --case generic_smoke.json
```

退出码：`0` 通过，`1` 门禁未通过，`2` 执行异常。

## 接入方式

无需修改代码，通过 JSON 目标配置接入。支持 HTTP、SSE 与 OpenAI 兼容接口，字段映射在 `response_map` 中配置。示例见 `平台/config.json`。

## 已知限制

- L2 模型评分存在波动，不单独作为判定依据。
- L3 依赖 trace 字段约定，目标未提供 trace 时无法执行。
- 校准集由六类手工构造的故障样本组成，覆盖面有限。
- Web 界面用于演示与调试，生产环境建议使用 `run.py` 的退出码。

## 实测记录

使用本平台测试一个开源智能体项目时，发现检索内容可直接拼入系统提示词，用户可通过知识库注入指令影响智能体行为。该缺陷已提交报告，并由维护者修复合并。
